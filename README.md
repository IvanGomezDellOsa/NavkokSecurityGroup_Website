# NavkokSecurityGroup — Sitio Corporativo

Rediseño completo del sitio web corporativo para **Navkok Security Group SRL**, empresa de seguridad privada con más de 30 años de trayectoria y certificaciones ISO 9001, 14001 y 45001. Proyecto freelance: desde la propuesta inicial hasta el sitio terminado.

🌐 **Vista previa:** [navkok-website-private.vercel.app](https://navkok-website-private.vercel.app/)

---

## 🛠 Stack

`Next.js 16` `TypeScript` `Tailwind CSS v4` `shadcn/ui` `Vercel`

---

## 🎨 Diseño y Assets

El sitio utiliza un sistema visual oscuro con acento dorado inspirado en estética de seguridad de élite. La paleta, tipografía y componentes fueron definidos desde cero para reflejar la profesionalidad de la empresa.

El video de fondo del hero fue generado con herramientas de IA y procesado con FFmpeg para compresión y recorte, priorizando el menor peso posible sin sacrificar calidad visual. Las imágenes del sitio fueron optimizadas en batch con Sharp, logrando reducciones de hasta un 90% en peso respecto a los archivos originales.

---

## 📝 Notas de Desarrollo

Proyecto freelance con contacto directo con el cliente. Relevé necesidades, propuse la arquitectura de contenido y el enfoque visual, redacté los textos institucionales e incorporé material propio — incluyendo imágenes y video generados con IA. El desarrollo fue asistido por LLMs para acelerar la maquetación y escritura de componentes. Las decisiones de producto, diseño y estrategia de contenido fueron tomadas y orquestadas por mí a lo largo de todo el ciclo.
